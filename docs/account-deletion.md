# WG Chores: delete your account

## In the app
Account → **Delete account** → type your username (SSO accounts: your display name) → confirm.

| Deleted at once | Kept |
|---|---|
| sign-in (password or SSO link), username, picture | your display name on completions you made, shown as "(former member)", so the household's history stays complete |
| all sessions and devices | households you were in (for the other members) |
| household memberships | |
| push subscriptions | |
| your open invite links (cancelled) | |

To have your display name removed from past completions too, ask the operator.

## Via the operator
Can't sign in any more, or want everything removed? Contact whoever runs the server you use.

| Server | Contact |
|---|---|
| `wg-chores.holy-grail.ch`, `wg-chores-demo.holy-grail.ch` (demo data is wiped every night anyway) | open an issue at https://github.com/tomigorn/WG-Chores/issues: say which server and your username, no passwords |
| any other server | its operator |
