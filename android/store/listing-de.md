```
Gemeinsames Haushalts-Logbuch für eure WG: wer hat was gemacht, und wann.
```

## Vollständige Beschreibung (4000)
```
WG Chores ist ein gemeinsames Logbuch für WG oder Haushalt. Nach einer Aufgabe tippst du sie an: alle sehen, wann sie zuletzt erledigt wurde und von wem.

Die App beantwortet eine Frage: «Wann wurde das zuletzt gemacht?» Das WC, das sauber aussieht, aber vor drei Wochen geputzt wurde, fällt auf, und niemand putzt die Küche doppelt, weil er nicht gesehen hat, dass es schon jemand gemacht hat.

Was die App kann
• Aufgaben nach Raum oder Kategorie, jede mit «zuletzt erledigt» und farbigem «Tage seit»
• Optionales Intervall pro Aufgabe (alle 3 Tage bis jährlich); die Farbe wird rot, wenn eine Aufgabe fällig ist
• Ein Tipp markiert eine Aufgabe als heute erledigt; lang drücken für ein anderes Datum oder eine Notiz
• Mehrere Haushalte pro Konto; Leute per Link einladen
• Benachrichtigungen, wenn eine Aufgabe fällig wird oder jemand anderes eine erledigt
• Erledigt-Markieren klappt auch offline und wird später synchronisiert
• Englisch und Deutsch, helles und dunkles Design

Was die App nicht macht
• Keine Punkte, Ranglisten oder Schuldzuweisungen: wer etwas gemacht hat, ist nur eine Information
• Keine Werbung, kein Tracking, keine Analyse

Dein eigener Server
WG Chores braucht einen WG-Chores-Server. Es gibt keinen zentralen Dienst: Beim Start gibst du die Adresse des Servers ein, den du nutzen willst. Du kannst deinen eigenen Server betreiben (ein kleiner Docker-Container); die Anleitung steht im Quellcode-Repository. Deine Daten liegen auf diesem Server, betrieben von wem auch immer ihn betreibt.

Der Server des Autors und ein öffentlicher Demo-Server sind nur zwei von beliebig vielen selbst betriebenen Servern; die Demo setzt ihre Daten jede Nacht zurück.

Quellcode: https://github.com/tomigorn/WG-Chores
```
