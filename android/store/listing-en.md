## Full description (4000)
```
WG Chores is a shared logbook for a flat share or household. After you do a chore, tap it: everyone sees when it was last done and by whom.

It answers one question: "When was this last done?" The toilet that looks clean but was cleaned three weeks ago becomes visible, and nobody cleans the kitchen twice because they missed that someone else already did.

What it does
• Chores grouped by room or category, each with "last done" and a coloured "days since" badge
• Optional interval per chore (every 3 days to every year); the colour turns red when a chore is due
• One tap marks a chore done for today; long press for another date or a note
• Several households per account; invite people with a link
• Notifications when a chore becomes due or someone else marks one done
• Marking done works offline and syncs later
• English and German, light and dark theme

What it does not do
• No scores, rankings or blame: who did a chore is shown as information, nothing more
• No ads, no tracking, no analytics

Your own server
WG Chores needs a WG Chores server. The app has no central service: when you start it, you enter the address of the server you want to use. You can run your own server (one small Docker container); setup instructions are in the source code repository. Your data lives on that server, run by whoever operates it.

The author's server and a public demo server are just two servers among any number of self-hosted ones; the demo resets its data every night.

Source code: https://github.com/tomigorn/WG-Chores
```
